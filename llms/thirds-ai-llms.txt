# thirds.ai

> Turn one design into content at scale.

Create branded images and PDFs for your campaigns and clients. Automate each new version through our API or your AI tools.

## What thirds.ai does

- Makes editable templates from a text prompt, your own HTML, a picture, or the gallery. Reuse each template with new data.
- Renders through the web app, the REST API at https://thirds.ai/v1, or the MCP server at https://thirds.ai/mcp.
- Outputs: PDF, PNG, JPEG, and WebP. A PDF can hold up to 100 pages. An image can be 320 to 7680 pixels wide and 200 to 4320 pixels tall.
- Keeps brand kits of logos, colours, and fonts. Select a kit for an AI build, or bind its fields in a template. A kit does not restyle hardcoded content.

## What thirds.ai does not do

- It does not load a page URL as the input. The API takes HTML text, or a saved template and a data object.
- It does not make video, Excel files, or animated images.
- A template starts as a PDF document or an image canvas. It does not turn one layout into every format on its own, so a new layout or aspect ratio can need edits.
- It does not host finished files at a public address. A signed download link lasts 15 minutes, and the file stays in the account for 30 days.

## Credits

- A verified account gets 50 free credits every month with no card.
- One finished PDF or image costs one credit. A failed render costs nothing.
- An AI template build or image import costs 50 credits. A later message with words or HTML costs 25 credits, and a later message with a new picture costs 50. Free credits do not pay for AI work. An AI build, import, or edit needs trial, pack, or plan credits. Copying a gallery template, hand edits, and the live preview are free.
- Credit packs cost $10 for 500 credits, $25 for 1,500, or $100 for 7,500, and last 12 months.
- Paid plans give 2,500 (Starter, $29 a month), 10,000 (Growth, $79), or 40,000 (Scale, $199) credits a month. Extra credits on a paid plan cost $0.015 each. Starter has a 7-day trial for $1 with 500 trial credits.

## Best recipes

1. HTML to PDF: POST https://thirds.ai/v1/pdf with {"html": "..."}. If queued or running, poll GET /v1/pdf/{id} with an application deadline and stop on failed or cancelled. On succeeded, resolve download.url against https://thirds.ai and download it without the API key. See https://thirds.ai/docs/quickstart.
2. HTML to image: POST https://thirds.ai/v1/image with {"html": "...", "image": {"format": "png", "width": 1200, "height": 630}}. See https://thirds.ai/html-to-image.
3. Template plus data: copy a gallery template, then POST /v1/pdf or /v1/image with {"template_id": "tpl_...", "version": 1, "data": {...}}. See https://thirds.ai/docs/templates-with-data.

Send an Idempotency-Key header with every create request, so a retry returns the same job. The OpenAPI contract is at https://thirds.ai/v1/openapi.json.
