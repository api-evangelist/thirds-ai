Turn one design into content at scale. thirds.ai makes editable templates from a text prompt, HTML, a picture, or gallery and renders PDFs and images via a web app, REST API, or hosted MCP server. Outputs are PDF, PNG, JPEG, and WebP.

**Areas:** pdf-automation · image-automation · Document Generation · HTML to PDF · HTML to Image · template-rendering · Branded Content · Developer Tools · MCP Server · Agent-Native · marketing-ops

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for thirds.ai: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
